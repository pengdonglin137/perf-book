# 性能分析中的术语和指标 {#sec:secMetrics}

与许多工程学科一样，性能分析大量使用特殊的术语和指标。对于初学者来说，查看由 Linux `perf` 或 Intel VTune Profiler 等分析工具生成的性能剖析可能非常困难。这些工具涉及许多复杂的术语和指标，但如果你想从事任何认真的性能工程工作，这些指标是"必须了解的"。

既然我提到了 Linux `perf`，让我简要介绍一下这个工具，因为我在本章和后续章节中有许多使用它的示例。Linux `perf` 是一个性能分析器，你可以用它来查找程序中的热点、收集各种低级 CPU 性能事件、分析调用栈等等。我将在本书中广泛使用 Linux `perf`，因为它是最流行的性能分析工具之一。我更喜欢展示 Linux `perf` 的另一个原因是它是开源软件，这使得热心的读者可以探索现代分析工具内部的工作机制。这对于学习本书中介绍的概念特别有用，因为基于 GUI 的工具（如 Intel® VTune™ Profiler）往往会隐藏所有复杂性。我们将在 [@sec:secOverviewPerfTools] 中更详细地介绍 Linux `perf`。

本章是性能分析中使用的基本术语和指标的简要介绍。我们将首先定义一些基本内容，如退休/执行指令、IPC/CPI、$\mu$ops、核心/参考时钟、缓存未命中和分支预测错误。然后，我们将了解如何度量系统的内存延迟和带宽，并介绍一些更高级的指标。最后，我们将对四个行业工作负载进行基准测试，并查看收集到的指标。
