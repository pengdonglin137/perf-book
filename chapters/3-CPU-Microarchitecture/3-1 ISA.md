## 指令集架构

指令集架构（ISA）是软件和硬件之间的契约，定义了通信规则。Intel x86-64、[^1] Armv8-A 和 RISC-V 是当前广泛部署的 ISA 的例子。所有这些都是 64 位架构，即所有地址计算使用 64 位。ISA 开发者和 CPU 架构师通常确保符合规范的软件或固件将在使用该规范构建的任何处理器上执行。广泛部署的 ISA 通常还确保向后兼容性，以便为处理器 GenX 版本编写的代码将继续在 GenX+i 上执行。

大多数现代架构可以归类为通用基于寄存器的加载-存储架构，如 RISC-V 和 ARM，其中操作数被显式指定，并且仅使用加载和存储指令访问内存。X86 ISA 是寄存器-内存架构，其中操作可以在寄存器以及内存操作数上执行。除了在 ISA 中提供基本功能（如使用整数和浮点数的加载、存储、控制和标量算术运算）之外，广泛部署的架构继续增强其 ISA 以支持新的计算范式。这些包括增强的向量处理指令（例如 Intel AVX2、AVX512、ARM SVE、RISC-V "V" 向量扩展）和矩阵/张量指令（Intel AMX、ARM SME）。广泛使用这些高级指令的应用程序通常会看到显著的性能提升。

现代 CPU 支持浮点和整数算术运算的 32 位和 64 位精度。随着机器学习和 AI 领域的快速发展，业界对替代数字格式重新产生了兴趣，以推动显著的性能改进。研究表明，机器学习模型使用更少的位数来表示变量时表现同样好，节省了计算和内存带宽。因此，大多数主流 ISA 最近添加了对较低精度数据类型的支持，如 8 位和 16 位整数和浮点类型（int8、fp8、fp16、bf16），以及传统的 32 位和 64 位算术运算格式。

[^1]: 在本书中，我经常简写为 x86，但我假设是 x86-64，这是 x86 指令集的 64 位版本，于 1999 年首次发布。此外，我使用 ARM 指代 ISA，使用 Arm 指代公司。
