## 核心周期与参考周期 {#sec:secRefCycles}

大多数 CPU 使用时钟信号来调节其顺序操作。时钟信号由外部生成器产生，该生成器每秒提供一致数量的脉冲。时钟脉冲的频率决定了 CPU 执行指令的速率。因此，时钟越快，CPU 每秒执行的指令就越多。
$$
Frequency = \frac{Clockticks}{Time}
$$
大多数现代 CPU（包括 Intel 和 AMD CPU）没有固定的运行频率。相反，它们实现了动态频率缩放，在 Intel CPU 中称为 *Turbo Boost*，在 AMD 处理器中称为 *Turbo Core*。它使 CPU 能够动态增加和减少其频率。降低频率以性能为代价降低功耗，而增加频率提高性能但牺牲了节能。

核心时钟周期计数器以 CPU 核心实际运行的频率计算时钟周期。参考时钟事件按处理器以基本频率运行的方式计算周期。让我们看看在 Skylake i7-6000 处理器上运行单线程应用程序的实验，该处理器的基本频率为 3.4 GHz：

```bash
$ perf stat -e cycles,ref-cycles -- ./a.exe
  43340884632  cycles		# 3.97 GHz
  37028245322  ref-cycles	# 3.39 GHz
      10,899462364 seconds time elapsed
```

`ref-cycles` 事件按没有频率缩放的方式计算周期。平台上的外部时钟频率为 100 MHz，如果我们按*时钟倍频器*缩放它，我们将获得处理器的基本频率。Skylake i7-6000 处理器的时钟倍频器等于 34：这意味着对于每个外部脉冲，当 CPU 以基本频率运行时（即 3.4 GHz），它执行 34 个内部周期。

`cycles` 事件计算实际 CPU 周期并考虑频率缩放。使用上面的公式，我们可以确认平均工作频率为 `43340884632 周期 / 10.899 秒 = 3.97 GHz`。当你比较一小段代码的两个版本的性能时，以时钟周期而不是纳秒来度量时间更好，因为你可以避免时钟频率上下波动的问题。
