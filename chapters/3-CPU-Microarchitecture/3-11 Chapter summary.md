## 本章小结 {.unlisted .unnumbered}

\markright{Summary}

* 指令集架构（ISA）是软件与硬件之间的基本契约。ISA 是计算机的抽象模型，定义了可用的操作和数据类型集合、寄存器集合、内存寻址方式等。你可以用多种不同方式实现特定的 ISA。例如，你可以设计一个优先考虑能效的"小"核心，或者一个面向高性能的"大"核心。
* 实现的细节被封装在 CPU"微架构"这个术语中。这个主题已经被数千名计算机科学家长期研究。多年来，许多巧妙的创意被发明并应用到量产 CPU 中。其中最引人注目的包括流水线、乱序执行、超标量引擎、推测执行和 SIMD 处理器。所有这些技术都有助于开发指令级并行性（ILP）并提升单线程性能。
* 与单线程性能并行地，硬件设计师开始推动多线程性能。绝大多数面向消费者的现代设备都配备了包含多个核心的处理器。有些处理器借助同步多线程（Simultaneous Multithreading，SMT）技术将可观察的 CPU 核心数量翻倍。SMT 使多个软件线程能够使用共享资源在同一物理核心上同时运行。这一方向上更新的技术称为"混合"（Hybrid）处理器，它将不同类型的核心组合在一个封装中，以更好地支持多样化的工作负载。
* 现代计算机的内存层次结构包含多级缓存，反映了访问速度与容量之间的不同权衡。L1 缓存最接近核心，速度快但容量小。L3/LLC 缓存较慢但容量更大。DDR 是大多数平台使用的主流 DRAM 技术。DRAM 模块在 rank 数量和内存宽度上有所不同，这可能对系统性能有轻微影响。处理器可以有多个内存通道，以同时访问多个 DRAM 模块。
* 虚拟内存是与 CPU 上运行的所有进程共享物理内存的机制。程序在访问时使用虚拟地址，虚拟地址会被转换为物理地址。内存空间被划分为页面。x86 的默认页面大小为 4KB，ARM 为 16KB。只有页地址会进行转换，页面内的偏移量按原样使用。操作系统在页表中保存转换映射，页表以基数树的形式实现。有硬件特性可以提升地址转换的性能：主要是转换后备缓冲区（TLB）和硬件页表遍历器。此外，开发者可以利用大页来缓解某些情况下地址转换的开销（参见 [@sec:secDTLB]）。
* 我们分析了 Intel 近期 Golden Cove 微架构的设计。从逻辑上看，核心分为前端和后端。前端由分支预测单元（BPU）、L1 I-cache、取指和解码逻辑以及 IDQ 组成，IDQ 将指令输送给 CPU 后端。后端由乱序执行引擎、执行单元、加载-存储单元、L1 D-cache 和 TLB 层次结构组成。
* 现代处理器具有封装在性能监控单元（PMU）中的性能监控功能。该单元围绕性能监控计数器（PMC）的概念构建，能够观察程序运行时发生的特定事件，例如缓存未命中和分支误预测。
