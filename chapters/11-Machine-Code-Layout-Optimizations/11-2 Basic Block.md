## 基本块 {#sec:BasicBlock}

*基本块*是具有单个入口和单个出口的指令序列。@fig:BasicBlock 显示了一个基本块的简单示例，其中 `MOV` 指令是入口，`JA` 是出口指令。如果控制流可以从 `BB1` 到 `BB2`，则基本块 `BB1` 是基本块 `BB2` 的*前驱*。类似地，如果控制流可以从 `BB2` 到 `BB3`，则基本块 `BB3` 是基本块 `BB2` 的*后继*。虽然一个基本块可以有一个或多个前驱和后继，但中间的指令不能进入或退出基本块。

![汇编指令的基本块。](../../img/cpu_fe_opts/BasicBlock.png){#fig:BasicBlock width=50% }

可以保证基本块中的每条指令将只执行一次。这是许多编译器转换所利用的重要属性。例如，它大大减少了控制流图分析和转换的问题，因为对于某些类别的问题，我们可以将基本块中的所有指令视为一个实体。
